# v5: 직전 행동 베끼기 막기 (기억 입력 지우기 + 전환 시점 가중치 + 좌우 반전)

> **대상: System 2 (판단 모델 Laya-S2)와 경로 헤드의 학습 데이터.** 모델 구조는 v4와 같다.

## 진단

**Isaac KIMM 주행 (2026-11-01, v4 `step_48000`)**: 같은 출발 위치에서 지시문 5개로 주행했다. 5번 모두 지시문과 관계없이 처음 8번을 우회전했다.

**저장 화면 시험** (`laya_work/copycat_check.py`)
- 화면 8장 × 지시문 2개, 모두 16개 경우다.
- 같은 화면에, 직전에 같은 방향으로 8번 돈 기록(화면·위치·명령)을 넣었다.

| 모델 / 입력 | 반대 방향 확률이 0.01 미만인 경우 | 회전 뒤 목표로 출발할 확률 |
|---|---|---|
| v4 전부 켬 | 16/16 | 0.32–0.35 |
| v4 움직임 토큰만 끔 | 16/16 | 0.32–0.37 |
| v4 위치·명령 모두 끔 | 9–12/16 | 0.37–0.43 |
| v3 `step_64000` (기억 입력 없음) | 12–14/16 | **0.71–0.74** |
| v2 `step_96318` | 15–16/16 | 0.48–0.55 |

- **반대로 안 도는 것은 v4만의 문제가 아니다.**
  - 전문가 경로에는 돌다가 반대로 도는 경우가 없다.
  - 그래서 과거 화면만 봐도 회전 방향을 알 수 있다.
- **v4는 계속 도는 쪽으로 기울었다.** 위치와 움직임 입력이 직전 행동을 더 직접 알려 준다.
- **v4의 오프라인 향상 중 일부는 이 지름길 덕일 수 있다.** 검증 데이터도 전문가 경로라서, 직전 행동을 따라 하면 점수가 오른다.
- **지시문을 거의 읽지 않는다.** 방향어를 바꿔도 좌·우 확률이 0.03–0.05만 바뀐다. 그래서 출발 화면이 같으면 첫 회전도 같다.

## 변경

모두 학습 샘플에만 적용하는 옵션이다. 끄면 v4와 같다.

| 변경 | 내용 | 인자 |
|---|---|---|
| 기억 입력 지우기 | 샘플마다 50% 확률로 위치·움직임 입력을 모두 0으로 만든다 | `--memory_dropout 0.5` |
| 전환 시점 가중치 | 정답이 직전 행동과 다른 샘플의 판단 손실을 3배로 한다 | `--w_change 3` |
| 좌우 반전 | 샘플마다 50% 확률로 장면 전체를 거울에 비춘다 | `--mirror 0.5` |

**전환 시점** (`change_flag`): 샘플 바로 앞 step의 행동과 정답을 비교한다.

| 정답 | 직전 행동 | 판정 |
|---|---|---|
| 목표로 출발 | 회전 | 전환 (돌다가 출발) |
| 목표로 출발 | 전진 | 유지 |
| 회전 | 같은 방향 회전 | 유지 |
| 회전 | 전진 또는 반대 회전 | 전환 |
| STOP, 첫 step | – | 제외. STOP은 이미 5배로 반복한다 |

모방 학습의 copycat 대책인 keyframe 가중치(Wen et al., ICML 2021)와 같은 방식이다.

**좌우 반전** (`mirror_instruction`, `mirror_poses`)

| 대상 | 바꾸는 방법 |
|---|---|
| 화면 | 과거·현재·내려다보기·경로 출발 화면을 모두 좌우로 뒤집는다 |
| 정답 | LEFT ↔ RIGHT, 목표 칸 가로 위치 x → 1 − x |
| 지시문 | left ↔ right (leftmost, right-hand 포함), clockwise ↔ counterclockwise |
| 위치·움직임 | y, 방향의 부호를 바꾸고, 명령의 좌 ↔ 우를 바꾼다 |
| 경로 정답 | 옆 방향과 방향 변화의 부호를 바꾼다 |

- **반전하지 않는 샘플**
  - 영어가 아닌 지시문 (RxR 힌디어·텔루구어)
  - right·left가 방향이 아닌 지시문 ("right in front of", "the room you just left" 등)
  - 교사 latent는 원래 샘플에서 뽑았으므로, 반전한 샘플에는 쓰지 않는다.
- **효과**: 같은 장면이 좌우 두 가지로 나온다. 어느 쪽으로 갈지는 지시문을 읽어야만 알 수 있다.

## 측정 추가 (`diagnose_decision.py --checks`)

기본으로 켜져 있다. 검증 샘플은 그대로 5,000개다.

| 지표 | 방법 | 보는 것 |
|---|---|---|
| 전환 / 유지 정확도 | 위 판정으로 나눠서 잰다 | 직전 행동으로 맞힌 몫과 실력으로 맞힌 몫 |
| `memory_off` | 위치·움직임 입력을 0으로 둔다 (v4 이후 모델만) | 기억 입력에 기대는 정도 |
| `swap_directions` | 지시문의 방향어만 바꾸고 화면은 그대로 둔다 | 판단이 바뀌는 비율, 좌 ↔ 우가 뒤집히는 비율 |
| `mirror` | 샘플 전체를 반전한다 | 반전 정확도, 반전 전 판단을 거울에 비춘 것과 일치하는 비율 |

학습 중 검증 로그에도 `acc_change`와 `acc_keep`이 나온다.

## 비용

- **파라미터**: 그대로 444.8M.
- **학습 시간**: 반전은 이미지 텐서를 뒤집기만 해서 거의 늘지 않는다. v4(1 epoch, 20.5시간)와 비슷할 것으로 본다.
- **진단 시간**: 체크포인트마다 검증을 최대 4번 돈다. 반전과 방향어 바꾸기는 해당 샘플만 돈다.

## 학습 (서버)

**1. 진단 먼저 (v3·v4, 학습 전)**

```bash
git pull
python scripts/train/laya_s2/diagnose_decision.py --vln_dataset_use r2r_125cm_0_30,rxr_125cm_0_30,scalevln_125cm_0_30 \
    --ckpts checkpoints/laya_nav_v3_c2/step_48000 checkpoints/laya_nav_v4_c2/step_48000 \
    --out_dir logs/diagnosis/v5_before
```

**2. v5 학습.** v4와 같은 시작점(v3 `step_48000`)과 설정에 옵션 세 개만 더한다. 그래서 v4와 v5의 차이는 이 세 가지뿐이다.

```bash
nohup torchrun --nproc_per_node=1 scripts/train/laya_s2/train_laya_nav.py --stage c2 \
    --init_from checkpoints/laya_nav_v3_c2/step_48000 \
    --vln_dataset_use r2r_125cm_0_30,rxr_125cm_0_30,scalevln_125cm_0_30 \
    --grounding 1 --w_match 0.2 --lr_text 1e-5 --max_text_len 256 \
    --num_history 32 --hist_recent 16 --hist_pose 1 --motion_tokens 8 --hist_grad 0 \
    --mirror 0.5 --memory_dropout 0.5 --w_change 3 \
    --epochs 1 --batch_size 32 --num_workers 16 --output_dir checkpoints/laya_nav_v5_c2 \
    > logs/laya_nav_v5_c2.log 2>&1 &
```

시작 로그에 `against copying the previous action: memory dropout 0.5 | change-point weight 3.0 | mirror 0.5`가 나와야 한다.

## 한계

- **회복은 여전히 못 배운다.** 전문가 경로에는 막히는 순간이 없다. 이 문제는 모델이 직접 주행한 기록에 정답을 붙이는 DAgger로 풀어야 한다([다음 후보](next_candidates.md) 6번).
  - DAgger 효과의 예: InternVLA-N1의 R2R-CE 성공률이 55.4 → 60.9(System 2), 58.2 → 64.1(듀얼)로 올랐다(InternNav README).
- **반전한 장면은 실제와 다를 수 있다.** 글자나 비대칭 가구 배치 같은 것이 그렇다. 그래서 50%만 반전하고, 반전하지 않은 원래 샘플도 그대로 학습한다.
- **방향어 바꾸기에는 정답이 없다.** 바꾼 지시문은 화면과 맞지 않는다. 그래서 이 지표는 판단이 바뀌는 정도만 본다.
