# 첫 C1의 실패 원인: System 1

> **대상: System 1 (경로 헤드).** C1은 System 2(판단 모델)와 공유 인코더를 고정하고 System 1만 학습하는 단계다. 아래 원인과 대응은 모두 System 1에 관한 것이다.

첫 C1은 r2r 데이터로 경로 헤드만 학습했고, 경로 예측이 좋지 않았다. 아래는 원본 DualVLN System 1과 코드를 비교해 찾은 원인이다. 각 변경의 효과는 아직 실데이터로 검증하지 않았다.

## 원인이 아닌 것

**정답 경로 생성**은 원본과 같다. 확인한 항목은 다음과 같다.
- 프레임과 pose의 정렬
- 경로 구간 (`start` ~ `start + goal_len`)
- 카메라 pitch 보정
- 0.1 m 재표본과 4배 스케일
- 32스텝 자르기 / 채우기

## 원인

### 1. 두 장면을 비교할 수 없는 구조

- 경로 헤드는 "목표를 정한 시점의 장면"과 "지금 장면"을 함께 받는다. 로봇이 이미 움직였다면, 둘을 대조해야 목표가 지금 화면 어디에 있는지 알 수 있다.
- **원본**: 두 프레임의 패치 전체에 self-attention을 3층 적용한다(`memory_encoder`).
- **v1**: 메모리 토큰끼리 attention이 없었다. 디코더 쿼리 32개가 각 패치를 따로 읽을 뿐이라, 두 프레임 패치를 직접 비교할 수 없었다.
- **v2**: 메모리 전체에 self-attention 2층(`traj_fuse`)을 추가했다.

### 2. 목표 위치가 흐릿하게 전달됨

- **원본**: 7B 모델이 목표 좌표를 텍스트로 출력한 뒤의 hidden state가 System 1 조건으로 들어간다.
- **v1**: 목표 위치가 판단 모델의 은닉 상태(목표 토큰)에 섞인 채로만 들어갔다. 목표 프레임의 196개 패치 중 어느 것이 목표인지 따로 표시되지 않았다.
- **v2**: 두 가지를 추가했다.
  - 목표 프레임에서 목표 주변 패치에 학습 벡터를 더한다(`traj_goal_mark`).
  - 목표 좌표를 별도 토큰으로 넣는다(`traj_goal_xy`).

### 3. 학습 신호 부족

- 목표 샘플 하나에는 경로 위의 출발 지점 후보가 여러 개(최대 12개) 있다.
- **원본**: 후보 전부를 학습한다.
- **v1**: 무작위 1개만 썼다. 특히 1번 능력이 필요한 "경로 중간에서 출발"하는 사례가 적었다.
- **v2**: 4개를 쓴다(`--traj_starts 4`). 비싼 판단 순전파는 한 번만 하고 공유한다.

### 4. (남은 요인) C1에서 고정된 이미지 특징

- **원본**: 이미지 백본(Depth-Anything)까지 같이 학습한다.
- **C1**: 정의상 경로 헤드만 학습하므로 SigLIP2 특징이 고정이다. SigLIP2는 의미 위주로 학습된 특징이라 거리·위치 같은 기하 정보가 약할 수 있다.
- **이번에는 바꾸지 않았다.** v2에서도 결정 시점 출발 경로가 평균 경로 수준이면 이 요인이 병목이다. 그때는 C2(전체 학습)로 넘어가거나 인코더 일부를 푼다.

## 요약 (모두 System 1)

| 원인 | 원본 System 1 | 첫 C1 (v1) | v2 대응 |
|---|---|---|---|
| 두 장면 비교 불가 | self-attention 3층 | 없음 | `traj_fuse` 2층 |
| 목표 위치 불명확 | 7B hidden state | 목표 토큰에 섞임 | `traj_goal_mark` + `traj_goal_xy` |
| 학습 신호 부족 | 출발 지점 최대 12개 | 1개 | 4개 |
| 고정된 이미지 특징 | 백본 학습 | 고정 | 그대로 (C2에서 학습) |

## C2 결과로 본 대응 효과 (2026-10-05)

| 원인 | 결과 |
|---|---|
| 1~3 (두 장면 비교, 목표 위치, 학습 신호) | v2 + C2에서 정답 목표 기준 ADE 0.09 m. 평균 궤적(0.52 m)의 약 1/6이므로 System 1의 경로 예측 문제는 해소된 것으로 본다 |
| 4 (고정된 이미지 특징) | C2에서 인코더까지 학습했고, 정답 목표 기준 경로가 정확하므로 현재는 병목이 아니다 |

남은 병목은 **System 2**다. 모델이 직접 고른 목표로는 ADE가 0.37 m로 커지고, 처음 보는 집에서 목표 패치 정확도는 0.45다. 자세한 내용은 [구현 보고서 11절](../IMPLEMENTATION_REPORT.md#11-현재-모델의-개선점과-한계-2026-10-06-c2-결과-기준).
