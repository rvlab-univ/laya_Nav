## 4. 해석

- **목표 선택**: 검증 acc_goal은 0.42 → 0.45로 올랐다가 그대로다. 학습 acc_goal은 0.59까지 올라 차이가 벌어진다.
- **과적합**: 검증 l_dec가 2.5 → 3.2로 오른다(C2는 4.2까지). 텍스트 학습률을 낮춘 효과로 C2보다 완만하다.
- **짝 맞추기**: acc_match가 0.68 → 0.81로 올랐다. 판단 모델이 지시문과 화면이 맞는지 구별하게 됐다.
- **경로**: ADE가 끝까지 줄었고 C2와 비슷하다.
- **체크포인트 선택**: 목표 선택 기준은 `step_48000`, 경로 기준은 `step_64000`이 후보다. 모델이 고른 목표 기준 경로 오차(`eval_traj.py --own_goal`)는 아직 재지 않았다.
- **서버 학습 중 오류**: 구절 캐시 버그(`KeyError: 'stairs'`)로 3,980 step에서 한 번 멈췄다. `grounding.py`에서 고쳤다.
